# QQ-Ad-Bot

基于 NoneBot2 + NapCat 的 QQ 群关键词计数广告自动发送机器人。

## 文档教学

https://www.yuque.com/g/shimo-31mqk/che31p/collaborator/join?token=qGCRTIh83UYcDaH7#

## 功能特性

- **关键词检测** — 监控群聊消息，匹配预设关键词（如"场照"、"接妆"、"接单"等）
- **随机阈值触发** — 每次发送后随机生成下一次触发阈值（默认 5-15 条），避免固定规律
- **延迟发送** — 触发后 30-90 秒随机延迟，模拟自然行为
- **模拟打字** — 发送前加入高斯分布的打字延迟（3-6 秒）
- **冷却时间** — 同一群最少间隔 2 小时才能再次发送
- **安静时段** — 默认凌晨 2:00-7:00 不发送消息
- **图文分开发送** — 支持文字和图片合并或分两条消息发送
- **Web 管理面板** — 可视化配置系统设置、群组管理、状态监控、NapCat 控制
- **授权管理** — 硬件绑定授权码机制，服务端在线验证

## 客户端部署

### 前置要求

- Windows 10/11（64 位）
- 无需安装 Python，exe 内置运行时

### 安装步骤

1. 将发布包解压到任意目录
2. 双击 `start.bat` 启动机器人
3. 浏览器自动打开管理面板 `http://127.0.0.1:8080/adbot/`

### 首次使用

1. **激活授权** — 在管理面板输入授权码完成激活
2. **登录 QQ** — 在 NapCat 控制区点击扫码登录，使用手机 QQ 扫描二维码
3. **配置群组** — 在群组管理中添加目标群，设置广告文案和图片
4. **开始投放** — 启用群组后，机器人自动监控关键词并发送广告

### 默认账号

- **用户名**：`admin`
- **密码**：`admin123`（首次登录请修改）
